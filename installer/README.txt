NOVA AI — OFFLINE DESKTOP EDITION

Nova installs completely on your Windows PC. The app, server and runtime are bundled;
nothing is downloaded during installation. Start it from Start menu or the desktop icon.

WHAT WORKS OFFLINE
- Nova interface, chat cards, settings, local file tools and browser automation UI.
- Local server starts automatically in the background.
- Your chats/settings stay in the browser profile you use with http://localhost:4173.

WHAT NEEDS INTERNET
- AI chat replies need an API key (Groq / NVIDIA / OpenAI-compatible provider).
- Image generation uses local Chrome/Edge via Bing when available; live-site worker
  needs this PC running. Click "Bing Login" in the Nova title bar once to sign in;
  the Chrome profile is kept in the app's workspace, so login persists after restart.

PRIVACY / STORAGE
- Data folder: %LOCALAPPDATA%\Nova AI\workspace
- Launcher log: %LOCALAPPDATA%\Nova AI\workspace\desktop-launcher.log
- Uninstalling Nova removes the installed app and its workspace.

SUPPORT
- Windows 10 or 11, 64-bit.
- Chrome or Edge recommended for Bing image tools.
